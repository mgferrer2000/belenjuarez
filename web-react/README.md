# Version historica React

Esta carpeta conserva la ultima version de la web desarrollada con React y
Vite. Desde el cierre de la migracion a Astro queda congelada como respaldo
historico.

No deben incorporarse aqui nuevos contenidos ni funcionalidades. El proyecto
activo esta en `../web-astro/` y es completamente independiente.

La copia puede seguir ejecutandose con:

```text
npm run dev
npm run build
```

Su conservacion permite consultar el comportamiento anterior o recuperar una
referencia visual sin condicionar la evolucion de la web Astro.
